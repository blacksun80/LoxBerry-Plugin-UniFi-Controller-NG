UniFi Controller NG

Runs the UniFi Network Application together with MongoDB in Docker and integrates it into LoxBerry. Requires a 64-bit LoxBerry with a running Docker Engine reachable by user loxberry.

Open the UniFi web interface on port 8443, create the admin user, and set the inform host on your UniFi devices (UniFi Devices → Device Updates and Settings → Device SSH Settings → Inform Host Override).

If a container fails to start, use the Diagnostics button - it collects the systemd status, container states, disk space and all logs.

Based on the original LoxBerry-Plugin-Unfi-Controller by Roman Lumetsberger. Project page
